# 🏆 Sports League Management System

## About the Project

The Sports League Management System is a web-based application developed using React.js. It helps administrators manage sports leagues and allows users to view league information.

## Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Vite
* Local Storage
* React Router DOM

## Modules

### 1. Admin Module

* Admin Login and Signup
* Manage Teams
* Manage Players
* Schedule Matches
* Manage Match Results
* View League Standings

### 2. User Module

* User Registration and Login
* View Teams
* View Players
* View Upcoming Matches
* View Match Results
* View League Standings

## Features

* Role-based Login
* Admin and User Dashboards
* Add, Edit and Delete Operations
* Local Storage Data Management
* Responsive User Interface
* Protected Routes

## Installation

1. Clone the repository.

   `git clone https://github.com/2500080007/sports-league-react.git`

2. Open the project folder.

   `cd sports-league-react`

3. Install dependencies.

   `npm install`

4. Run the application.

   `npm run dev`
